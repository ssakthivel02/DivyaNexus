# Shiva Legacy Migration Contract

Target legacy site: `shiva.omsaravanabhava.org`
Source product: DivyaNexus

## Scope
The legacy site becomes Shiva-centred while preserving DivyaNexus's broader Vedic knowledge base. Existing Vedas, Upanishads, Bhagavad Gita, Vishnu/Perumal, Devi, Ganesha, Murugan, temple, Siddhar and philosophy content must not be deleted merely for rebranding.

## Non-negotiable rules
- Preserve source labels, citations, provenance and confidence metadata.
- Expand Shiva/Parvati/Nataraja/Chidambaram and related Shaiva knowledge additively.
- Do not commit credentials, private user data or secrets.
- Preserve privacy, legal, PWA/offline and accessibility behaviour.
- Keep repository history intact; work through this migration branch and PRs.
- Do not merge unrelated RamaVerse, KirthiVerse or SaravanaBhava codebases.
- DNS/Cloudflare changes are a separate controlled cutover after repository validation.

## Migration phases
1. Legacy domain and branding baseline.
2. Shiva-centred information architecture without deleting broad Vedic content.
3. SEO/legal/PWA brand sweep.
4. Build, route and source-integrity validation.
5. DNS cutover and live smoke test.
